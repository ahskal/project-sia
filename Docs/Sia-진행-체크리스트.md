# Sia 진행 체크리스트

이 문서는 구현 상태와 선택 전 아이디어를 구분해 관리합니다. 기준 문서는 [구현 계획](PLAN.md), [채집 구현 기록](Resource-Harvesting-Plan.md), [아이디어 통합 정리](Project-Sia-아이디어-통합-정리.md)입니다.

## 상태 기준

- `[x]` 코드 구현을 확인했습니다. 자동화 검사 결과는 별도 항목에 기록합니다.
- `[~]` 코드 구현은 있지만 실제 플레이에서 동작을 확인해야 합니다.
- `[ ]` 미구현이거나 아직 결정하지 않았습니다.
- `보류`는 구현 범위에서 제외했지만 아이디어는 보존합니다.

## 구현 완료

- [x] 캐릭터 이동, 점프, 대시, 카메라와 기본 공격·피해·체력·HUD 기반을 구현했습니다.
- [x] 아이템 데이터, 인벤토리 스택·무게·장비 슬롯·퀵슬롯, 픽업·소비·버리기와 UI 기반을 구현했습니다.
- [x] 나무 5종 중 하나를 선택하고, 공격 시 넘어지며 통나무와 확률 사과를 드롭합니다. 크기별 수량은 프로필 데이터로 조정합니다.
- [x] 나무 몸통 충돌이 Pawn을 막습니다. 프로필에서 몸통 반지름과 높이를 조절합니다.
- [x] 바위 3종과 짝이 맞는 Chaos Geometry Collection을 연결했습니다. 체력에 따라 메시와 충돌 크기가 줄고, 파괴 시 자원 충돌이 꺼집니다.
- [x] 바위 타격 조각은 공격 위치와 무관하게 바깥쪽부터 분리됩니다. 바위는 돌을 드롭하고 3초 뒤 제거됩니다.
- [x] 도끼·망치·곡괭이·괭이·삽 장착, 도끼의 나무 추가 피해, 곡괭이의 바위 추가 피해를 연결했습니다.
- [x] 양손 공격 판정, 같은 공격의 중복 타격 방지, 입력 예약, `MM_Attack_01`과 `MM_Attack_02` 교대 재생을 구현했습니다.
- [x] UE 5.8 에디터 빌드와 격리 프로젝트 자동화 검사 16개가 통과했습니다. 자세한 검사 범위는 [채집 구현 기록](Resource-Harvesting-Plan.md#확인한-항목)을 참고하세요.

## 직접 플레이 확인

아래 항목은 사용자가 실제 플레이에서 확인했습니다.

- [x] 실제 플레이어 메시에서 양손 공격 판정이 맞는 위치에 켜집니다.
- [x] 도끼·망치·곡괭이·괭이·삽의 손 위치와 방향을 확인했습니다.
- [x] 나무에 접근할 수 있고 몸통이 플레이어 이동을 막습니다.
- [x] 바위에 접근할 수 있고 체력에 따라 작아지며 파괴 후 이동을 막지 않습니다.
- [x] 실제 레벨 지형에서 나무·돌 픽업이 바닥에 놓이고 인벤토리에 들어갑니다.
- [x] 여러 형태의 지면에서 나무가 넘어지는 방향과 통나무 드롭을 확인했습니다.

## 구현되지 않은 항목

- [ ] 나무 본체의 타격 위치 기반 Chaos 파쇄. 현재는 나무가 넘어지고 작은 물리 조각을 만듭니다.
- [ ] 방어구 능력치를 받는 피해에 반영합니다.
- [ ] 몬스터 AI, NPC 대화·퀘스트, 레벨·스탯 성장을 구현합니다.
- [ ] 싱글플레이 완료 후 멀티플레이 복제를 설계합니다.

## PIE에서 확인할 항목

- [ ] 공격 몽타주가 타격 구간과 맞고 연속 공격 입력이 두 동작으로 이어지는지 확인합니다.
- [ ] 사과 확률 드롭을 여러 차례 채집해 확인합니다. 현재 기본 확률은 18%입니다.

## 구현 보완 및 다음 단계

### 먼저 진행할 작업

- [ ] 위 PIE 항목을 확인하고, 화면에서 보이는 충돌·도구 위치를 조정합니다.
- [ ] 첫 플레이의 시작 지점, 성공 조건, 포함할 지역·적·목표를 정합니다.
- [ ] 공격·피격·사망 애니메이션과 공격 구간의 히트박스 동작을 완성합니다.
- [ ] 방어구 능력치가 받는 피해에 반영되게 합니다.
- [ ] 인벤토리가 가득 찼을 때 픽업이 사라지지 않도록 처리하고 실제 플레이에서 확인합니다.

### 싱글플레이 수직 슬라이스

- [ ] 몬스터 대기·추적·공격·피격·사망과 데이터 기반 드롭을 구현합니다.
- [ ] NPC 대화, 단일 목표 퀘스트, 진행 표시와 보상을 연결합니다.
- [ ] 경험치·레벨·스탯 성장 규칙을 정하고 UI에 표시합니다.
- [ ] 이동, 채집, 인벤토리, 전투, 퀘스트, 보상, 완료 지점을 한 번의 플레이로 연결합니다.
- [ ] 시작부터 완료까지 자동화 검사와 PIE로 전체 흐름을 확인합니다.

### 나중에 진행할 작업

- [ ] 싱글플레이 흐름을 검증한 뒤 멀티플레이 서버 권한과 상태 복제를 별도 설계합니다.
